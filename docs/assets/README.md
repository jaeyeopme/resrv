# Documentation Assets

This directory contains visual assets and source files used for review or presentation material.

These files are not a source of truth for product, architecture, API, security, or operational
behavior. Use `README.md`, `docs/prd.md`, `docs/trd.md`, `docs/architecture.md`,
`docs/security.md`, `docs/testing.md`, `docs/operations.md`, `docs/glossary.md`, and `docs/adr/`
for current system documentation.

Some assets may describe an earlier reservation MVP and can lag behind the current platform +
timeslot redesign.
